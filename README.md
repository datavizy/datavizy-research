# Logic Notes

Original educational research notes from a technical reading practice. Data visualization, statistical reasoning, and reproducible scientific analysis.

Each weekday note develops a selected book section into an accessible explanation, worked examples, practical applications, and exercises. Every note cites its source. Source books and extracted passages are kept in the private local library.

- [Read the publication index](INDEX.md)
- [Browse the append-only glossary](GLOSSARY.md)
- [Explore developer utilities, scientific research tools, and automation](https://github.com/datavizy/developer-utilities)

## Format

Articles live in `articles/`; dated glossary additions in `glossary-entries/`; source hashes, generation records, and validation summaries in `metadata/`. Each publication is introduced through a pull request and merged into the default branch.

The notes are independently written, AI-assisted explanations. Worked examples and assumptions are stated explicitly; the collection grows Monday through Friday.
